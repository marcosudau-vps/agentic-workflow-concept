# Allgemeines Konzept

Die Dokumente dieses Bereichs beschreiben das Gesamtsystem in sachlicher, rollenunabhängiger Form. Sie enthalten weder Quellen-/Entscheidungshistorie noch offene Arbeitsaufträge. Der dargestellte Zusammenhang ist ein umfassender, stark abgesicherter Systemmodus mit vorgelagerter Planungs- und Härtungsphase.
