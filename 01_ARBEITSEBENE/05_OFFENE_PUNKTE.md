# Offene Fragen zur späteren Themenprüfung

Dies ist eine **Arbeitsakte**; keine offenen Fragen in die neutrale Konzeptebene übertragen.

- Wie weit soll ein Planhardener trotz strikter Änderungsverbote Werkzeuge/Tests/Prototypen verwenden dürfen? Er soll jedenfalls keine fachliche Planautorität erlangen.
- Benötigt der Architekt eine immer eigenständige Session oder reicht ein spezialisiertes Prüfgate unter Verantwortung des Planners?
- Welche eindeutigen Nachweisgrenzen gelten, wenn externe Agenten dieselbe Plattformidentität verwenden?
- Wie wird das geplante „nur ein Feature zugleich auf Release“ mit sicher vorgeplanten parallelen Arbeitslinien praktisch umgesetzt?
- Wie werden standübergreifende Freigaben und originale menschliche Prompts bei mehreren Repositories gesichert?
- Welche Semantik haben Hotfixes bei bereits freigegebenem Feature oder Release?
- Wie wird maschinell nachweisbar, dass alle Konzeptregeln in den operativen Artefakten umgesetzt sind?
- Welche Schnittstelle wird ein späterer CLI-Adapter (Codex, Claude Code, Copilot, OpenCode) haben? Noch keine aktive Integration.
- Welche Bedingungen erlauben erst am Ende Abschwächungen für kleinere Projekte?

Diese Punkte blockieren nicht die Bereitstellung des zusammenhängenden Initialmodells auf dem Entwicklungsbranch. Sie sind ausdrücklich Gegenstand der Themenbesprechungen.
