# Rollen-Skills und vorgesehene Lesepfade

**Gemeinsamer Einstieg**: [`dispatcher/SKILL.md`](dispatcher/SKILL.md) für „ermittle den nächsten zulässigen Schritt“. Er lädt [Statusregeln](GEMEINSAM/references/STATUS_UND_GATEPRUEFUNG.md) und die betroffene Rollenreferenz, nicht pauschal die gesamte Planung.

| Rolle | Einstieg | Selektive Zusatzlektüre |
| --- | --- | --- |
| Planner | [planner](planner/SKILL.md) | Planungsprozess, Kontrakt-/Traceabilityregel, Planaktualisierung |
| Architect | [architect](architect/SKILL.md) | Zielbild/Architektur, relevante Verträge, Architekturcheckliste |
| Hardener | [hardener](hardener/SKILL.md) | genaue Planbaseline, Härtungsauftrag, Findingformat |
| Planreviewer | [plan-reviewer](plan-reviewer/SKILL.md) | konsolidierter Plan, vorige Findings/Dispositionsbelege |
| Implementer | [implementer](implementer/SKILL.md) | freigegebenes AP, betroffene Verträge, Tests, Run- und Gitregel |
| Technical Reviewer | [reviewer](reviewer/SKILL.md) | kompletter Kandidaten-Diff, Evidence, Review-/Gitregel |
| Canonicalizer | [canonicalizer](canonicalizer/SKILL.md) | PASS, Originalfreigabe, Head/Base/Tree/CI, Abschlussregel |
| Feature Qualifier | [feature-qualifier](feature-qualifier/SKILL.md) | Paketaggregate, vollständige Feature-DoD, Integration/Builds |
| Release Qualifier | [release-qualifier](release-qualifier/SKILL.md) | Releaseumfang, RC-Matrix, Artefaktdigests, Crossrepo-Paare |

Gültige Projekt-AGENTS/Policies und tatsächlicher Auftrag werden vor Aktionen geprüft. **Sessionunabhängigkeit und minimale Kontextladung** sind Bestandteil der Rolle.
